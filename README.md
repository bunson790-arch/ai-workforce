# AI Workforce

An autonomous AI company platform where specialized AI employees work across departments to build, manage, operate and grow businesses.

## Department Core Frontend

The frontend now uses a central AI Company Core with the eight departments arranged in a networked command-center layout:

1. CEO & Executive Management
2. Marketing Department
3. Communications Department
4. Sales Department
5. Research Department
6. Technology Department
7. Human Resources & Administration
8. Finance & Payments Department

### Run locally

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

This is the frontend-only department map. Department data and external integrations are separate implementation phases.
